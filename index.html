Cart Abandonment Prediction

A full ML pipeline on ~4,280 e-commerce sessions across 13 behavioral attributes — missing-value imputation, Box-Cox normalization, feature selection via RFE and Random Forest importance narrowed to 5 key signals, and SMOTE to correct class imbalance. The final Logistic Regression model reached ~98% accuracy (Cohen's Kappa 0.94 on held-out test data), then wrapped in a small Flask app for real-time predictions.
